# Чем занято место на VPS

Измерение 26.09.2026, в рамках обновления документации и копии проекта. Размеры ниже — десятичные ГБ, поэтому цифры в панели провайдера могут отличаться из-за единиц и задержки обновления.

На момент начала этой проверки файловая система занимала **21,40 ГБ**. После очистки неиспользуемого Docker build cache — **11,77 ГБ**, свободно **28,66 ГБ** из 40,48 ГБ. Фактически освобождено около **9,64 ГБ**. Сам Docker сообщил удаление 10,88 ГБ логического кэша; эта величина не равна изменению занятого места из-за общих слоёв.

| Состав | Примерный размер | Что сделано |
|---|---:|---|
| Docker/containerd: образы и их слои | 5,38 ГБ | Рабочие образы и откат сохранены |
| Docker: тома, метаданные, журналы | 0,43 ГБ | Рабочие данные сохранены; сюда временно входит тестовая БД для скриншотов |
| Системный swapfile | 2,15 ГБ | Системный файл, оставлен |
| `/usr`: ОС, библиотеки и утилиты | 2,06 ГБ | Оставлено |
| `/root/backups` | 0,64 ГБ | Резервные копии сохранены |
| `/opt/gspro-updates` | 0,48 ГБ | Отчёты, исходники релизов и резервные копии сохранены |
| `/opt/gspro` | 0,024 ГБ | Рабочий сайт и конфигурация |
| Прочие системные каталоги и метаданные | Остаток | Без изменений ОС |

Удалён именно неиспользуемый кэш сборок командой `docker builder prune --all --force`. Образы работающих контейнеров, база, секреты, архивы и системные настройки не удалялись. Кэш можно заново получить при следующей сборке; на работу запущенного сайта он не влияет. В момент измерения тестовое окружение для руководства ещё работает; оно будет удалено после создания скриншотов.


Финальная проверка: занято 11 781 574 656 байт, свободно 28 642 652 160 байт. Временные тестовые контейнеры и тома удалены. HTTP главной страницы — 200, рабочие web/Mini App/бот/PostgreSQL healthy. Свежий закрытый архив сохранён отдельно от GitHub.
