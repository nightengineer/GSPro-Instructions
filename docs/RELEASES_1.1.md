# Два варианта релиза 1.1

| Версия | DEPLOY_MODE | PLATEGA_ENABLED |
|---|---|---|
| production-1.1 | production | true |
| no-production-1.1 | no-production | false |

Это два варианта конфигурации одного исходного кода, со своими VERSION и тегами образов. Снимок БД общий, сделан в один момент. Создание production-бэкапа не включает платежи на работающем сайте. С сентября 2026 в БД есть `TechnicalSettings.checkoutEnabled`: если оно задано, оно имеет приоритет над `PLATEGA_ENABLED`. Поэтому один профиль `no-production-1.1` без явного отключения поля БД больше не гарантирует закрытие новых платежей. Актуальные команды отключения устанавливают оба значения.

`gspro-stage5-vps` — историческое внутреннее имя Compose-проекта и его постоянных томов, не номер релиза. Менять его на действующем сервере без переноса томов нельзя: Docker может подключить пустую базу. Команды переключения показывают явную версию вместо технических имён контейнеров.

Новые env и шаблоны не содержат SELLER_TYPE, SELLER_NAME, SELLER_INN, SELLER_OGRN, SELLER_LEGAL_ADDRESS, SELLER_POSTAL_ADDRESS, SELLER_PHONE. Синхронизация окружения удаляет эти поля повторно, если они добавлены вручную. SELLER_EMAIL и необходимые ключи/пароли остаются.

## Резервирование

Новый полный зашифрованный снимок содержит `RELEASES.json`, оба `variants/<версия>/application.tar.gz`, общие БД/состояние бота и образы с тегами обеих версий. Все файлы покрываются SHA256SUMS. Прежние каталоги production-1.1 и no-production-1.1 описаны как исторические комплекты восстановления.

При восстановлении сначала проверить расшифровку и SHA256SUMS. Для выбранной версии используйте её application.tar.gz вместо корневого application.tar.gz, остальные данные из того же снимка. Установщик поддерживает `RELEASE_VARIANT=production-1.1` или `RELEASE_VARIANT=no-production-1.1`. По умолчанию восстанавливается текущая версия снимка. Не запускать два экземпляра бота или два сайта с одной рабочей базой одновременно.

Исторические снимки Prod-1.1/Prod-1 сохраняют состояние на дату создания и не переименовываются в новые версии. Старые env внутри таких архивов остаются историческими; они не являются актуальными шаблонами.
