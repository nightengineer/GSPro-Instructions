# GSPro: карта системы

Карта исходников: 28.09.2026.

Магазин и административная Mini App работают с общей PostgreSQL. Caddy разделяет публичные маршруты. Бот получает события через закрытый API Mini App.

## Как читать карту

- Покупатель использует магазин в браузере или установленной PWA.
- Сотрудник использует web-админку либо Mini App с проверкой Telegram и 2FA.
- Сервер проверяет текущие права на каждую операцию; интерфейс не является границей защиты.
- Внешние сервисы: Telegram API, Platega, SMTP/почтовый API, DNS/HTTPS и два независимых закрытых S3-хранилища (Timeweb и REG.RU).
- GitHub хранит исходники. Полное восстановление требует полного приватного снимка, независимого recovery-kit из доступного S3 и исходных ключей.

## Точки входа в исходниках

`compose.yaml`, `deploy/Caddyfile`, `app/app`, `telegram-admin/app`, `telegram-bot/worker.mjs`.

Схема описывает проверенную структуру кода, а не обещает доступность внешних сервисов или успешный последний запуск резервирования.
