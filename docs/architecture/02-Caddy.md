# HTTPS и Caddy

Карта исходников: 26.09.2026.

Caddy - публичная точка входа. Магазин и Mini App слушают внутренний порт 3000; PostgreSQL - внутренний 5432.

## Маршруты

| Запрос | Куда направляется |
| --- | --- |
| `/` и остальные страницы | `web:3000` |
| `/tg-admin` и вложенные пути | `telegram-admin:3000` |
| `/api/internal/*`, `/tg-admin/api/internal/*` | Снаружи ответ 404 |
| `/tg-admin/api/health` | Снаружи ответ 404 |

В Compose опубликованы 80/tcp, 443/tcp и 443/udp. Данные сертификатов сохраняются в `caddy_data` и `caddy_config`. DNS и доступные порты необходимы для HTTPS. Закрытие маршрута на прокси дополняет, но не заменяет серверную авторизацию.

Исходники: `deploy/Caddyfile`, `compose.yaml`.
