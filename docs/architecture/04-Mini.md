# Telegram Mini App

Карта исходников: 28.09.2026.

Отдельное Next.js-приложение на `/tg-admin`. Предназначено для административных действий внутри Telegram, использует ту же PostgreSQL и политику прав.

## Авторизация

1. Проверяется Telegram initData: подпись и срок.
2. Telegram ID связывается с пользователем и действующим StaffAccess.
3. Проверяется 2FA; выдаётся ограниченная по сроку сессия.
4. Каждый запрос сверяет актуальный доступ и sessionVersion.

Web/mini/bot - отдельные разрешённые каналы StaffAccess. Изменение политики роли действует и для уже открытой Mini App. Действия по заказу из кнопок бота открывают Mini App, а не обходят MFA.

Часть библиотек и Prisma-схема продублированы из web. При изменении общей логики проверяйте обе копии и сборки.

Исходники: `telegram-admin/lib/mini-auth.js`, `mini-crypto.mjs`, `admin.js`, `admin-permissions.js`, `telegram-admin/app/api/admin`.
