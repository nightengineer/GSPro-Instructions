# SMTP и уведомления

Карта исходников: 28.09.2026.

Почта разделена по операциям: recovery, order, marketing, support. Регистрация использует recovery. Профили SMTP и адреса отправителей настраиваются отдельно.

## Доставка

`mailer.js` выбирает SMTP, настроенный почтовый API либо явно разрешённый локальный тестовый режим. SMTP-пароль хранится зашифрованным; для восстановления необходим исходный ключ почты.

Покупатель управляет письмами об ответах поддержки. Сотрудник отдельно подписывается на оплаты и сообщения покупателей. Получатели каждый раз фильтруются по действующему доступу, 2FA, политике роли и подписке. Настройка подписки не расширяет права.

Письма сотрудникам и покупателю об ответе сообщают номер заказа и предлагают открыть защищённый интерфейс; игровые пароли в эти шаблоны не включаются. Наличие уведомления в БД не доказывает доставку письма.

Бизнес-письма отправляются по текущему best-effort механизму. Надёжная общая outbox-очередь с повторной доставкой требует отдельной реализации. Отчёты backup используют свою служебную очередь и настройки получателей.

Исходники: `app/lib/mailer.js`, `mail-profiles.js`, `mail-preferences.js`, `notifications.js`, `app/app/api/account/mail-preferences/route.js`, `deploy/backup-notify.mjs`.
