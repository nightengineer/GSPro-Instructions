# GSPro: архитектура для Obsidian

Актуальность: 28.09.2026. Карта составлена по исходникам этого выпуска; секреты и персональные данные не включены.

## Открыть карту

1. В Obsidian выберите «Открыть папку как хранилище» и укажите **docs/architecture**.
2. Откройте **GSPro.canvas**. Это Canvas JSON с узлами, связями, группами и карточками реальных Markdown-файлов.
3. Дважды щёлкните карточку для полного текста. Для общего вида используйте масштаб «показать всё».

Файлы карточек указаны относительно этого хранилища. Если открывать весь репозиторий как vault, сначала измените `file` в Canvas на `docs/architecture/<имя файла>`; исходный вариант специально рассчитан на отдельную папку архитектуры.
