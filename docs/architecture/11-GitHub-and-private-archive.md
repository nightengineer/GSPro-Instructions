# GitHub и приватный архив

Карта исходников: 28.09.2026.

Два разных результата передачи: исходники для разработки и закрытый комплект для восстановления. Один не заменяет другой.

| GitHub / исходный репозиторий | Только закрытая передача |
| --- | --- |
| Код, Dockerfiles, lock-файлы | Рабочие `.env` и исходные ключи |
| Prisma schema и миграции | Дампы PostgreSQL и реальные данные |
| Тесты на синтетических данных | SQLite состояния Telegram-бота |
| Markdown, Canvas, технические PDF | Полные backup-архивы и ключ восстановления |
| Очищенные `.env.example` | SSH/S3/SMTP/Platega/Telegram credentials |

`.gitignore` исключает `.env*` (кроме шаблона), дампы, архивы, ключи, базы SQLite, логи и служебные каталоги. Ignore не удаляет секрет, уже попавший в Git: публикацию всегда проверяют по индексу и истории.

Переменные `NEXT_PUBLIC_*` могут попасть в клиентскую сборку; приватные значения в них не помещают. В архитектурных карточках нет рабочих credentials и персональных данных.

Исходники: `.gitignore`, `.env.example`, `.github/workflows`, `docs/production/Восстановление`.
