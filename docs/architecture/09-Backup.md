# Полная резервная копия

Редакция: **28.09.2026**. Закрытый snapshot дополняет публичные инструкции: сохраняет БД, исходные ключи, образы, SQLite бота и материалы восстановления.

## Текущий серверный порядок

Действующая система находится в `/root/backups/scripts/`: `backup.py`, `s3_store.py`, `multi_s3_store.py`, `publish_recovery.py`, `recover.py` и скрипты уведомлений. Системные службы и конфигурации относятся к конкретному VPS; публичный репозиторий не заменяет их приватный комплект.

1. Создать согласованный снимок приложения, PostgreSQL и состояния бота; контролировать остановку и последующий запуск писателей.
2. Сохранить полный набор исходников, ключей и env, сведения о контейнерах и образах. Текущий комплект один: web, Mini App, бот, PostgreSQL и Caddy — пять образов.
3. Зашифровать полный архив CMS/AES-256-GCM по сертификату получателя.
4. Загрузить в Timeweb и REG.RU, проверить точные байты/SHA256 обратным чтением, записать квитанции. При сбое одного хранилища ожидающая копия сохраняется на VPS до успешного повтора.
5. Выполнить принятую ротацию и отправить служебное уведомление. Перед очисткой нужны свежий успех обоих S3 и пригодность выбранного снимка для восстановления.

В каждом S3 отдельно хранится независимый `gspro/recovery-kit/`: инструкции, downloader, tools и защищённый приватный PEM. Он доступен без старого VPS. Пароль PEM и S3 credentials владелец хранит отдельно. Старые версии ключа из `gspro/recovery-keys/` нужны для соответствующих прежних снимков.

Полный архив может содержать env, дампы и системные конфигурации. Полный kit включает защищённый приватный ключ. Ни то, ни другое не публикуют в GitHub. SHA256 не заменяет доверенный источник и репетицию восстановления.

`recover.py` возвращает контейнеры, остановленные прерванным backup, по сохранённому маркеру. Он не расшифровывает снимки и не восстанавливает потерянный VPS или БД.

Проверяйте `s3_store.py check`, свежий `/root/backups/multi-s3-last-success.json`, выбранную дату архива и наличие полного kit. Исторические наборы снимков в двух S3 могут отличаться.
