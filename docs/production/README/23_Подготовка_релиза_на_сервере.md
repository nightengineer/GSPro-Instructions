# Подготовка релиза на сервере

Редакция: **28.09.2026**.

Рабочий сайт находится в `/opt/gspro`. Подготовьте отдельный закрытый каталог в `/root/gspro-releases/`, скопируйте в него актуальные исходники нужных компонентов и внесите правки.

Перед выпуском выполните проверки с отдельной тестовой базой и отключёнными внешними отправками. Для развёртывания используйте `/opt/gspro/deploy/deploy-release.sh КАТАЛОГ_РЕЛИЗА НОВЫЙ_ТЕГ`. Подробный порядок: `17_Выпустить_новую_версию.md`.

Перед выпуском проверьте актуальную квитанцию загрузки в оба S3 и доступность выбранного снимка. Закрытый ключ восстановления и пароль храните раздельно по инструкции `09_Сохранить_и_восстановить_ключи.md`.
