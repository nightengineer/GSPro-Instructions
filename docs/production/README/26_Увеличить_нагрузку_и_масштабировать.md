# Увеличить нагрузку и масштабировать

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Перед ростом трафика измерить задержки, ошибки, CPU/RAM/swap, соединения БД, длительность снимков и очередь бота. На текущем VPS около 2 ГБ RAM; сборки лучше выполнять отдельно от обслуживания клиентов.

Перед несколькими web-репликами сделать общий rate limiter и проверить фоновые задачи/сессии/идемпотентность. Бот должен оставаться единственным активным обработчиком своего токена. Изменение архитектуры требует обновления backup/restore и теста восстановления.
