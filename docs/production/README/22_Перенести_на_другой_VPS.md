# Перенести на другой VPS

Для последнего полного S3-снимка используйте [интерактивный мастер на чистом Ubuntu](../../../server-setup/Инструкция_настройки_GSPro.md). Следующий текст сохраняет справочный порядок исходного комплекта и его дату.

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Следовать `../Восстановление/01_На_новый_VPS.md`. Подготовить новый пустой Ubuntu 24.04 x86-64, публичный SSH-ключ владельца, S3-доступ и пароль защищённого ключа.

Развёртывание сначала закрытое: не включать второго бота, не направлять клиентов на непроверенную БД. После проверки сделать финальный snapshot на старом VPS, остановить его обработчики и только затем переключать единственный рабочий экземпляр/DNS.
