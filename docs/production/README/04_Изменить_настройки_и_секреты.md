# Изменить настройки и секреты

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Исходные настройки: `/opt/gspro/.env` и `.env.telegram`, права 600. `.env.runtime` формируется автоматически `deploy/sync-runtime-env.py`: вручную его не редактировать.

Перед изменением создать резервную копию. После правки сначала выполните [check-env.sh](34_check_env.md). Затем пересоздайте только затронутые сервисы: `deploy/dc up -d --no-deps --no-build --pull never --force-recreate --wait web` (замените web соответствующим сервисом). Обычный restart не применяет новое окружение. При изменении NEXT_PUBLIC_* нужна также пересборка; изменение пароля в .env не меняет пароль роли PostgreSQL.

Ключи APP_ENCRYPTION_KEY_BASE64, GAME_CREDENTIALS_KEY_BASE64 и MAIL_ENCRYPTION_KEY связаны с данными в БД. Их нельзя просто заменить случайными: понадобится расшифровка старым ключом и контролируемое повторное шифрование. SESSION_SECRET сменит проверку сессий. Не писать секреты в README, Git, логи, команды со значениями в истории shell.
