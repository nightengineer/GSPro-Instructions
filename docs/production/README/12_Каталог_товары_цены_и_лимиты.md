# Каталог товары цены и лимиты

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Админка → Каталог → нужная игра. Здесь задаются активность, платформа, необходимые поля аккаунта, готовые наборы, своё количество, лимит заказа и комиссии.

Перед сохранением проверить состав набора, розничную цену и прибыльность. Покупателю показывается конечная цена; внутренняя комиссия не должна становиться публичным полем. «Комиссия платёжного сервиса» — текст уведомления, сам по себе не меняет сумму. При пустом поле в текущем оформлении выводится стандартное предупреждение Platega, поэтому пустое значение не следует считать отключением уведомления.

После правки проверить карточку, оформление, граничные значения и поведение уже открытого оформления. Старый подписанный расчёт должен быть отвергнут при изменении существенных условий. Не запускать seed на рабочей БД для обычного редактирования.

Поиск админки работает по названию, адресу игры и издателю; скрытые игры отображаются отдельным переключателем. RU/EN редактируются в форме игры, изображения, цены и включение общие. Подробные шаги, режимы полей аккаунта и новые действия удаления с 2FA описаны в [полном руководстве](../../ADMIN_GUIDE.md). Повторная сверка файлов VPS 27.09.2026 подтвердила наличие удаления игры с 2FA в вебе и Mini App. Исторические заказы, переписка и аудит сохраняются; новые покупки по удалённой игре запрещены.
