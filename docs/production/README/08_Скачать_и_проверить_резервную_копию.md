# Скачать и проверить резервную копию

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

1. Выбрать файл `.cms` в нужном дневном/месяччном префиксе S3 и соответствующий `.sha256`.
2. Скачать оба файла по защищённому доступу. До расшифровки проверить SHA256 (`sha256sum` на сервере).
3. Получить защищённый `.encrypted.pem` из `gspro/recovery-keys/` и пароль из менеджера паролей.
4. Расшифровать через `Восстановление/decrypt-cms-stream.py`. Скрипт проверит AES-GCM и не сохранит частичный результат при ошибке.
5. Распаковать в новый закрытый каталог, выполнить `sha256sum -c SHA256SUMS` и прочитать BACKUP-FORMAT.json.

Для доказательства восстановления дополнительно восстановить PostgreSQL в изолированной сети, проверить SQLite, изображения, секреты и входы. Одного SHA256 недостаточно для проверки логической полноты БД.
