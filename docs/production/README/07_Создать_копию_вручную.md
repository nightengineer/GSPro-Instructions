# Создать копию вручную

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

```bash
systemctl start gspro-backup@daily.service
systemctl show gspro-backup@daily.service -p Result -p ExecMainStatus
journalctl -u gspro-backup@daily.service -n 40 --no-pager
```

Для месячной копии заменить daily на monthly; перед изменениями — на pre-release. Блокировка предотвращает одновременный деплой/снимок. Сайт, Mini App, бот и proxy кратко останавливаются для согласованного состояния; загрузка больших файлов выполняется после их запуска.

Успех означает создание зашифрованного архива и проверку обратного чтения из обоих S3. Если сервис завершился ошибкой, проверить дисковое место, S3, маркер `/root/backups/restart-needed.json` и health сервисов. Не запускать несколько ручных копий подряд.

После завершения сверьте /root/backups/multi-s3-last-success.json: нужен свежий результат выбранного снимка для обоих хранилищ. Наличие скрипта или старой квитанции не подтверждает текущий успех. При ошибке одного S3 копия должна оставаться на VPS до успешного повтора; не удаляйте её вручную.
