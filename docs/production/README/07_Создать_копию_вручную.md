# Создать копию вручную

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

```bash
systemctl start gspro-backup@daily.service
systemctl show gspro-backup@daily.service -p Result -p ExecMainStatus
journalctl -u gspro-backup@daily.service -n 40 --no-pager
```

Для месячной копии заменить daily на monthly; перед изменениями — на pre-release. Блокировка предотвращает одновременный деплой/снимок. Сайт, Mini App, бот и proxy кратко останавливаются для согласованного состояния; загрузка больших файлов выполняется после их запуска.

Успех означает создание зашифрованного архива и проверку обратного чтения из S3. Если сервис завершился ошибкой, проверить дисковое место, S3, маркер `/root/backups/restart-needed.json` и health сервисов. Не запускать несколько ручных копий подряд.

Реализация активных /root/backups/scripts, конфигурация и systemd units не входят в этот локальный снимок исходников. Описанные расписание, остановка сервисов и обратная проверка S3 основаны на прежнем серверном регламенте: перед обслуживанием сверьте действующие units, протокол и квитанцию. Наличие поставочных deploy/backup*.sh само по себе не доказывает настройки работающей службы.
