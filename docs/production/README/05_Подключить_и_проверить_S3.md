# Подключить и проверить S3

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Endpoint: `https://s3.twcstorage.ru`; регион: `ru-1`; bucket: `c621752d-bf59-48fc-bc71-eaad18817ae8`.

Настройки транспорта — `/root/backups/s3-config.json`. Ключи S3 — `/root/backups/s3-credentials.json`, только root (600). Доступ bucket должен быть закрытым. Префикс архивов: `gspro/backups/`. Учётным данным нужны операции чтения/записи/списка и удаления объектов только согласованного bucket/префикса.

```bash
python3 /root/backups/scripts/s3_store.py check
cat /root/backups/last-s3-daily-success.txt
```

Перед удалением локального архива загрузчик получает его из S3 и сверяет SHA256; затем сохраняет квитанцию в `s3-receipts`. ETag многокомпонентной загрузки не принимается за SHA256 всего архива. Проверка подписи CMS и восстановление БД выполняются отдельно.
