# Изменить домен и HTTPS

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

1. Подготовить DNS нового домена и доступ к консоли провайдера. Сначала проверить запись A/AAAA и порты 80/443.
2. Изменить DOMAIN в `/opt/gspro/.env`, публичные ссылки в обоих env, настройках сайта и Telegram/Platega.
3. Пересобрать web и Mini App с новым публичным URL, поскольку часть ссылок задаётся при сборке. Выпускать с новым тегом.
4. Проверить Caddyfile, редирект www, HTTPS, вход, callback, sitemap и ссылки писем.

Сертификаты хранятся в томе Caddy. Не копировать `/etc` целиком между VPS. Ошибку сертификата не обходить отключением TLS-проверки.
