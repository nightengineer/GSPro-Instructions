# Добавить новую функцию и тесты

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Зафиксировать пользовательский сценарий и критерии приёмки. Изменять минимальный нужный участок; общие правила обновлять в web/Mini App синхронно. Для прав доступа/денег/backup обязательны негативные проверки и испытание отказов.

В app/ выполняйте `node scripts/source-check.mjs`, `npm test` и `npm run build`; в telegram-admin/ — `npm test` и `npm run build`; в telegram-bot/ — `node --test *.test.mjs`. В снимке 27.09.2026 telegram-admin/package.json указывает npm run check на отсутствующий scripts/source-check.mjs, поэтому этот alias нельзя считать рабочей проверкой Mini App без исправления поставки. Интеграционные проверки выполняются только на отдельной БД/сети без реальных писем, бота и платежей.

Для нового типа настройки добавить отдельный русскоязычный файл в README и обновить оглавление. Перед релизом обновить папку восстановления и проверить полноту snapshot.
