# Безопасно освободить место

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Сначала выполнить `df -h /`, `docker system df`, проверить активные контейнеры/тома, последний S3 snapshot и возможность восстановления.

Наиболее безопасные кандидаты: неиспользуемый build cache и apt-кэш. Старые тестовые образы, rollback-контейнеры и исторические архивы требуют сверки с действующим релизом и восстановления из актуальной копии.

Не выполнять общий `docker system prune --volumes`. Не удалять `/var/lib/docker` вручную. Не удалять database/telegram_state/caddy_data/caddy_config, env, ключи, конфигурацию S3, текущие образы и папку восстановления.

Конкретный список и объём перед чисткой фиксировать в отдельном отчёте. Старый архив может содержать историю, которой нет в новой БД; удаление такой истории должно соответствовать принятому сроку хранения.
