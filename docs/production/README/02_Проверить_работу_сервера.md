# Проверить работу сервера

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

```bash
cat /opt/gspro/VERSION
/opt/gspro/deploy/dc ps -a
curl --fail https://gspro.store/api/health
df -h /
free -m
systemctl --failed
systemctl list-timers 'gspro-*'
```

Нормально: web, telegram-admin, telegram-bot и db — healthy; Caddy работает. Контейнер миграции может завершиться с кодом 0. Health проверяет доступность БД; HTTP 200 не означает подключённые реальные платежи.

Для общей проверки существующей установки: sudo bash /opt/gspro/deploy/start-and-check.sh --check-only. [Параметры и пределы проверки](33_start_and_check.md). VERSION сообщает записанный тег, а не результат сравнения файлов и запущенного образа. deploy/dc может обновить производные env-файлы; вывод полной Compose-конфигурации и docker inspect не публикуйте.
