# Сверить платёж и оформить возврат

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Платёж подтверждается проверенным callback или серверной сверкой провайдера. Возврат браузера на success URL не является подтверждением.

Сверка: systemd `gspro-platega-reconcile.timer`. Ручная проверка известного UUID из кабинета: `deploy/dc exec -T web node scripts/platega-reconcile.mjs UUID`.

UNKNOWN без transactionId требует поиска в кабинете мерчанта. Не создавать повторное списание вслепую. Поздний CHARGEBACKED/двойная оплата требуют разбирательства. Изменение статуса заказа на «Возвращён» само по себе не отправляет деньги: сначала выполнить операцию возврата по согласованному процессу и сохранить её подтверждение.
