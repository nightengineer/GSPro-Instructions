# GSPro — обслуживание установленного сайта

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Эта папка описывает текущую систему и основные задачи её изменения. После новой функции добавляйте отдельную инструкцию: невозможно заранее перечислить все будущие доработки. Не хранить здесь секреты.

## Статус установки

Редакция: **28.09.2026**. Проверяйте действующие службы и выбранный снимок перед обслуживанием. Полная установка на новом VPS и внешняя приёмка в этой актуализации не выполнялись.
