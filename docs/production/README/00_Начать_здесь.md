# GSPro — обслуживание Prod-1.1

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Эта папка описывает текущую систему и основные задачи её изменения. После новой функции добавляйте отдельную инструкцию: невозможно заранее перечислить все будущие доработки. Не хранить здесь секреты.

## Статус установки

[СТАТУС_ВНЕДРЕНИЯ.md](СТАТУС_ВНЕДРЕНИЯ.md) — исторический отчёт 24.09.2026. Инструкции сверены с локальным снимком исходников VPS от 27.09.2026; эта сверка не подтверждает текущие S3, бэкапы, SMTP, платежи или работоспособность новых функций в запущенных образах. Значение VERSION и наличие файла не доказывают успешную сборку.
