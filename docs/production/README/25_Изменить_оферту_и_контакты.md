# Изменить оферту и контакты

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Редактировать через админку, сохранять новые версии документов. Проверить все ссылки и реальные контакты, особенно в сохранённых текстах БД: изменение env не заменяет их автоматически.

Изменения юридической модели/кассы/обработчиков согласовать с ответственным специалистом. Флаги подтверждения в env — внутренние проверки запуска, а не автоматическое подтверждение соответствия. Не заменять реальную проверку простым true.

При наличии нового редактора проверьте отдельно RU и EN; изменение русского текста помечает прежний перевод как требующий проверки. [Подробности RU/EN](../../TRANSLATIONS_RU_EN.md). Политика deploy/dc удаляет семь устаревших SELLER-полей из env; сведения продавца и сохранённые юридические тексты проверяйте в текущем контенте приложения.
