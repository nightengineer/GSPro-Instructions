# Заменить S3 или ключи доступа

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Создать доступ к новому закрытому bucket. Скопировать актуальные архивы, защищённый ключ восстановления и квитанции/контрольные суммы; проверить обратное чтение и расшифровку.

Изменить endpoint/bucket/region/credentials в root-конфигурации, проверить `s3_store.py check`, выполнить ручную дневную копию. Старое хранилище удалять только после подтверждённого восстановления и решения по истории.

При ротации Access/Secret сначала установить новый доступ и проверить работу, затем отозвать старый. Пароль защищённого PEM не совпадает с S3 Secret Key.
