# Заменить S3 или ключи доступа

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Создать доступ к новому закрытому bucket. Скопировать актуальные архивы, полный независимый recovery-kit, соответствующие защищённые версии ключа и контрольные суммы; проверить обратное чтение и расшифровку.

Изменить endpoint/bucket/region и соответствующий credentials-файл одного выбранного S3 в root-конфигурациях, проверить `s3_store.py check`, выполнить ручную дневную копию и подтвердить её свежую квитанцию в обоих S3. Не принимайте прежнюю квитанцию за проверку нового хранилища. Старое хранилище удалять только после подтверждённого восстановления и решения по истории.

При ротации Access/Secret сначала установить новый доступ и проверить работу, затем отозвать старый. Пароль защищённого PEM не совпадает с S3 Secret Key.
