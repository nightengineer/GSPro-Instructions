# Как устроен сайт

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Сайт работает через Caddy → web / telegram-admin → PostgreSQL. Telegram-бот — отдельный процесс, его служебное состояние хранится в SQLite. Mini App входит в ту же систему и в каждую полную копию.

`app/` — сайт; `telegram-admin/` — Mini App; `telegram-bot/` — бот; `deploy/` — команды обслуживания; `README/` — эти инструкции; `Восстановление/` — аварийный комплект.

`VERSION` хранит записанный тег выпуска; в снимке 27.09.2026 это footer-note-20260927-01a0e21b. Наличие более новых файлов не доказывает их сборку в работающие образы. Имена Compose-проекта и существующих томов исторические (`gspro-stage5-vps`): это постоянные адреса данных, их не переименовывать при смене версии. Все команды ниже используют `/opt/gspro/deploy/dc` и не зависят от имени контейнера.
