# Настроить расписание и хранение копий

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Дневной снимок — 03:15 по Самаре; месячный — первого числа в 03:45. S3: 7 последних календарных дней и 12 последних месяцев. Повтор в тот же период заменяет актуальный вариант периода после проверки новой копии. Перед выпуском сохраняется одна последняя страховочная pre-release копия.

На VPS постоянно остаётся последняя дневная копия. Во время создания/ошибки возможны временные или ожидающие загрузки файлы: их нельзя удалять, пока S3 не проверено.

Изменять `/root/backups/config.json`, `/root/backups/s3-config.json` и соответствующие units `/etc/systemd/system/gspro-backup-*.timer` согласованно. После изменения расписания: `systemctl daemon-reload`, затем перезапуск нужного timer. Число 0 в retention запрещено.

Все снимки содержат web, Mini App, bot, дамп БД, SQLite, Docker-образы, настройки и папку восстановления. Это прикладной комплект восстановления, не поблочный образ диска VPS.
