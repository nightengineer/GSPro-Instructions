# Изменить схему базы данных

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Используется PostgreSQL 17 и Prisma. Одинаковая схема должна находиться в web и Mini App; изменения оформляются отдельной миграцией.

Сначала проверить на копии данных. В production применять `deploy/dc run --rm migrate`, не `db push` и не development reset. Административная роль нужна только миграциям; приложение работает ограниченной ролью.

Перед изменением есть проверенный snapshot. Добавление столбца обычно допускает старый код; удаление/перенос данных требует отдельного плана совместимости. После миграции проверить историю, права, сборки и оба интерфейса.
