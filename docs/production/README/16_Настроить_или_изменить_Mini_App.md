# Настроить или изменить Mini App

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Исходники — `/opt/gspro/telegram-admin`. URL: `https://gspro.store/tg-admin`. На входе проверяется подпись и срок Telegram initData, затем права в БД.

Закрытый Mini App API должен отвечать 401 гостю; внутренние маршруты proxy скрывает 404. Изменение Caddy/CSP должно сохранять совместимость с Telegram WebView.

Изменения общих API, каталога, схемы Prisma и настроек дублируются согласованно в web и Mini App. Выполнять обе сборки и тестировать реальные Telegram iOS/Android/Desktop. Полная копия всегда содержит исходники и Docker-образ Mini App.
