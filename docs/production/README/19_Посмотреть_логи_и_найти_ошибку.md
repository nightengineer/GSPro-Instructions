# Посмотреть логи и найти ошибку

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

```bash
/opt/gspro/deploy/dc logs --tail 100 web telegram-admin telegram-bot
journalctl -u gspro-backup@daily.service -n 60 --no-pager
journalctl -u gspro-backup-notify.service -n 30 --no-pager
journalctl -u gspro-platega-reconcile.service -n 30 --no-pager
```

Не публиковать логи без проверки на токены, email, UID и платёжные ссылки. Docker-логи имеют ротацию. При отказе S3 локальные незагруженные копии сохраняются. При отказе всего VPS его собственная почта тоже недоступна — нужен независимый мониторинг вне сервера.
