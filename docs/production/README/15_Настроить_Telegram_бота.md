# Настроить Telegram бота

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Настройки — `.env.telegram`; исходники — `telegram-bot/`. Bot token хранится только на сервере. Внутренний URL ведёт на Mini App в Docker-сети.

Бот использует SQLite-том `gspro-stage5-vps_telegram_state`. Не удалять его: там состояние переписки/тем/обработки. Копия включает этот том в telegram-state.tar.gz.

После изменения токена/URL пересоздать telegram-bot через dc и проверить health, получение заказа и ответ покупателю. Одновременно два экземпляра с одним токеном не запускать. Для переноса сначала остановить старый бот, затем сделать финальный снимок.
