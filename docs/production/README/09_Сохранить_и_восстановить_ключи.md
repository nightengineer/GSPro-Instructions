# Сохранить и восстановить ключи

Редакция: **28.09.2026**.

Установленный GSPro. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

На VPS только публичный сертификат CMS и отдельно защищённый паролем приватный PEM. В каждом S3 текущий защищённый ключ находится в `gspro/recovery-kit/keys/`; сохранённые версии — в `gspro/recovery-keys/`. Не публикуйте даже защищённый приватный PEM.

Пароль защищённого PEM нужно хранить отдельно от S3 — в личном менеджере паролей. Он не записывается в конфигурацию VPS. Потеря пароля и исходного приватного ключа делает архивы невосстановимыми.

Для восстановления текущего снимка получите защищённый PEM вместе с независимым recovery-kit; для снимка под прежним ключом выберите соответствующий PEM из `gspro/recovery-keys/` в S3; пароль берите из отдельного менеджера паролей. Сохраняйте доступ к ключам всех действующих архивов.

Нельзя хранить единственную копию ключа только внутри архива, который зашифрован этим же ключом. Обновляя ключ, сохранять старый до истечения срока хранения всех его архивов.

Смена только пароля PEM не меняет сам приватный ключ и совместимость прежних архивов. Смена самого ключа требует сохранения прежнего PEM и его пароля для всех оставшихся снимков. Проверяйте доступ к обоим S3 и ключам независимо от сохранности VPS.
