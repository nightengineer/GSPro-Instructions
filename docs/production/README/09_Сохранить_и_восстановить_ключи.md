# Сохранить и восстановить ключи

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

На VPS только публичный сертификат CMS и отдельно защищённый паролем приватный PEM. В S3 приватный ключ хранится в отдельном объекте `gspro/recovery-keys/`, не в открытом виде.

Пароль защищённого PEM нужно хранить отдельно от S3 — в личном менеджере паролей. Он не записывается в конфигурацию VPS. Потеря пароля и исходного приватного ключа делает архивы невосстановимыми.

Для восстановления получите защищённый PEM из `gspro/recovery-keys/` в S3; пароль берите из отдельного менеджера паролей. Сохраняйте доступ к ключам всех действующих архивов.

Нельзя хранить единственную копию ключа только внутри архива, который зашифрован этим же ключом. Обновляя ключ, сохранять старый до истечения срока хранения всех его архивов.
