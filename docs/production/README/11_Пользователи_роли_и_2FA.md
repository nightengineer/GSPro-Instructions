# Пользователи роли и 2FA

Версия комплекта: **Prod-1.1**. Основная папка сайта: `/opt/gspro`. Команды выполняются на VPS по SSH от root, если не указано другое.

Управление сотрудниками выполняется в админке через раздел доступов. SUPER_ADMIN — владелец; ADMIN — менеджер; CHAT_OPERATOR — оператор чата; USER — покупатель. Отдельно выдаются каналы web/Mini App/bot.

`StaffAccess` определяет допуск по каналам; `StaffRolePolicy` — уровни доступа ADMIN и CHAT_OPERATOR по разделам. Владельцу доступен редактор политик, сотрудники видят только разрешённые окна; сервер повторно проверяет право на каждом запросе. Старые `operators.txt`/`admins.json` не возвращают доступ. При изменении роли проверяются права текущей и назначаемой роли; отдельно проверяйте принятие приглашения, отключение сотрудника и отзыв сессий.

Владельцам и сотрудникам включить TOTP, сохранить резервные коды отдельно. Без действующей 2FA административные окна недоступны. Отключение 2FA из профиля требует свежий пароль и одноразовый код на подтверждённую почту; после отключения административный доступ прекращается до повторного включения. При потере доступа использовать [инструкцию восстановления владельца](../Восстановление/Восстановить_доступ_владельца.md). Не откатывать публичный сайт к версии без проверки 2FA.
