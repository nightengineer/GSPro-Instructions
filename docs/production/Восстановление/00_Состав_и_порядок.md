# Комплект восстановления Prod-1.1

Полный snapshot содержит database.dump, globals.sql, application.tar.gz (web/Mini App/bot/README/этот комплект), telegram-state.tar.gz, proxy-volumes.tar.gz, images.tar.gz, ssh-client.tar.gz, system/, images.json, containers.json, SHA256SUMS и BACKUP-FORMAT.json.

Восстановление на новый сервер: `01_На_новый_VPS.md`. После сбоя действующего: `02_После_падения_текущего_VPS.md`. Начать с проверки SHA256, расшифровки и внутренних SHA256SUMS. Не использовать частичный или неаутентифицированный вывод.

Ключ восстановления берётся из отдельного защищённого PEM в S3; пароль хранится отдельно в менеджере паролей. Ключ S3 даёт доступ к объектам; он не заменяет пароль расшифровки приватного PEM.

Сверка 27.09.2026 подтверждает наличие исходников аварийных скриптов, но не нового защищённого snapshot, его образов, базы, приватных env или S3. Репозиторий не заменяет полный архив. Проверки расшифровки и восстановления из старых отчётов относятся к их датам; выбранный для переезда архив проверяется заново.
