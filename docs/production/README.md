# Эксплуатация установленного GSPro

Сайт: https://gspro.store. Корень установленного VPS: /opt/gspro. Команды этих инструкций предназначены для SSH-сеанса администратора. В этой актуализации команды обслуживания не выполнялись.

Документация сверена с локальным снимком исходников VPS от **27.09.2026**. VERSION снимка: footer-note-20260927-01a0e21b. Снимок файлов может включать изменения после последней сборки: VERSION не доказывает, что все описанные функции уже есть в работающих образах. Исторические отчёты 23–25 сентября сохранены с датами; их проверки S3, платежей, резервных копий и сборок не повторялись.

Серверная обёртка deploy/dc объединяет compose.yaml, compose.telegram.yaml и compose.miniapp.yaml и перечитывает .env/.env.telegram. Она также обновляет .env.runtime и применяет политику удаления устаревших полей SELLER; это не полностью read-only команда. Она не пересоздаёт контейнеры без соответствующей команды Compose.

[Переносимый install.sh](../DEPLOY.md) предназначен для нового VPS и не заменяет действующие серверные процедуры. Публичные исходники не включают рабочие env, базы, готовые образы, S3 credentials и весь комплект /root/backups: проверьте полноту защищённого архива перед восстановлением.
