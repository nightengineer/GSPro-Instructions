# Эксплуатация установленного GSPro

Редакция: **28.09.2026**. Сайт: https://gspro.store. Корень установленного VPS: `/opt/gspro`. Команды предназначены для SSH-сеанса администратора.

Инструкции описывают текущий комплект приложения и резервирования. Полная установка на новом VPS, реальные платежи и доставка внешних уведомлений в этой актуализации не выполнялись. Проверяйте состояние служб, квитанции и выбранный снимок перед обслуживанием.

Обёртка `deploy/dc` объединяет `compose.yaml`, `compose.telegram.yaml` и `compose.miniapp.yaml`, перечитывает `.env`/`.env.telegram`, обновляет `.env.runtime` и применяет политику окружения. Она не пересоздаёт контейнеры без соответствующей команды Compose.

Для нового пустого VPS используйте мастер и полный приватный recovery-kit из S3 вместе с выбранным снимком. Публичный репозиторий не содержит рабочих env, БД, готовых образов, S3 credentials или приватного ключа. Один текущий комплект содержит пять образов; новые продажи переключаются галочкой в админке, без второго комплекта приложения.
