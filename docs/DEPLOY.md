# Восстановление GSPro на новом сервере

Используйте пустой Ubuntu 24.04 x86_64 и полный собственный S3-снимок. Сохранённые образы рассчитаны на `gspro.store`, корень приложения - `/opt/gspro`.

1. [Интерактивный мастер: самый простой способ](../server-setup/Инструкция_настройки_GSPro.md), [PDF](../server-setup/Инструкция_настройки_GSPro.pdf).
2. [Ручное независимое восстановление из S3](recovery/Восстановление_из_S3.md), [PDF](recovery/Восстановление_из_S3.pdf).
3. [Эксплуатация уже установленного VPS](production/README.md), [выпуск изменений](production/README/17_Выпустить_новую_версию.md).

Установка восстанавливает сохранённые исходники, ключи, PostgreSQL, SQLite и пять образов. Сайт, Mini App, бот и расписание копий запускаются после проверки и решения о переключении. Публичный GitHub содержит документы и инструменты; закрытые данные получают из своего S3.
