# Security notes

- Не хранить `.env` в Git; секреты держать в KMS/secret manager.
- Использовать разные значения для Session, UID HMAC, IP HMAC, checkout token и AES key.
- Ротация AES-ключа требует версионированного re-encryption job; текущий формат имеет префикс `v1`.
- Ограничить доступ к PostgreSQL частной сетью, включить TLS, резервные копии и проверку восстановления.
- In-memory rate limiter заменить общим Redis limiter при нескольких репликах.
- Прокси должен перезаписывать, а не принимать от клиента доверенные `X-Forwarded-For`.
- Разрешить callback только по HTTPS; при наличии стабильных IP провайдера добавить allowlist на reverse proxy.
- Сверять сумму/валюту callback с исходным заказом после уточнения фактической схемы payload провайдера. Сейчас статус привязывается к заранее созданному order payload, а сумма заказа не берётся из callback.
- Настроить мониторинг повторных 401/503 callback, неотправленных уведомлений и частых reveal UID.
- Админов защищать MFA/SSO на уровне access proxy; встроенная парольная роль — минимальный автономный контур.
- Не включать UID в Telegram без оценки трансграничной передачи и минимизации данных.
