# Матрица юридических требований и реализации

| Контур | Реализация | Что заполнить/проверить оператору |
|---|---|---|
| Информация о продавце | Футер, `/legal/requisites`, оферта; ИНН, ОГРН/ОГРНИП, адрес, телефон, email | Фактические реквизиты и статус ИП/ООО |
| Заключение договора | Итоговая цена, состав, номер заказа до оплаты; версия оферты в Consent | Роль сервиса и предмет договора с поставщиками |
| Персональные данные | Отдельный пустой чекбокс, версия, время, IP-HMAC, UA; политика и согласие | Уведомление оператора, перечень обработчиков, локализация, сроки |
| Немедленное исполнение | Самостоятельный обязательный чекбокс | Согласовать формулировку с фактической услугой |
| Реклама | Необязательный чекбокс, не влияет на заказ | Каналы, отписка, доказательства согласия |
| Cookie | Необходимые всегда; аналитика/маркетинг off-by-default; повторные настройки в футере | Перечень фактически подключённых счётчиков и сроки |
| Оплата | Реквизиты карты не проходят через приложение; серверная ссылка и callback | Договор с Platega, allowed domains, callback, возвраты |
| Чеки | Preflight требует подтверждения фискализации | ККТ/агентская схема и корректные признаки расчёта |
| Возвраты/претензии | Нет blanket «возвратов нет»; номер обращения; форма/email/адрес | Регламент, сроки, полномочия сотрудников |
| Удаление | Запрос, завершение сессии, отложенная анонимизация, purge | Утвердить retention schedule и обязательные сроки учёта |
| Несовершеннолетние | Подтверждение 18+ либо согласия законного представителя | Выбрать допустимую модель аудитории и верификации |
| Трансграничная передача | Telegram UID off; двойной флаг и stop-gate | Выполнить необходимые оценки и документирование до включения |
| Социальное доказательство | Live-лента помечена «Демо-данные» | Подключать только проверенные реальные события без лишних ПД |
