# Основной сайт GSPro

Next.js и PostgreSQL обслуживают витрину, заказы, кабинет и веб-админку. Установленные исходники находятся в `/opt/gspro/app`, серверные команды выполняются из `/opt/gspro` через `deploy/dc`.

- [Сайт и административный интерфейс](../docs/ADMIN_GUIDE.md).
- [Эксплуатация](../docs/production/README.md).
- [Восстановление нового сервера](../server-setup/Инструкция_настройки_GSPro.md).
- [Изменение и выпуск кода](../docs/production/README/17_Выпустить_новую_версию.md).

При восстановлении используются PostgreSQL dump, исходные ключи, сохранённые образы и состояние бота из полного S3-снимка. Приём новых оплат переключается в админке через `TechnicalSettings.checkoutEnabled`. Для работы на существующих данных не запускают создание демонстрационной базы вместо восстановления.
