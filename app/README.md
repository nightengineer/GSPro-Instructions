# GSPro Prod-1.1 — основной сайт

Приложение Next.js с PostgreSQL: витрина, заказы, кабинет и административный интерфейс. Это один компонент релиза Prod-1.1; Mini App и бот находятся в соседних каталогах.

Актуально на 26.09.2026. [Обслуживание текущего VPS](../docs/production/README.md), [установка и перенос на новый VPS](../docs/DEPLOY.md), [руководство по админке со скриншотами](../docs/ADMIN_GUIDE.md). Dockerfile основного сайта: `../deploy/Dockerfile`, контекст сборки — этот каталог. Compose запускается из корня проекта через `bash deploy/dc`.

Для локальной разработки использовать отдельную тестовую базу и `.env.example`. Не выполнять seed, db push или privacy purge на восстановленной рабочей базе как часть установки. Восстановление выполняется из PostgreSQL dump, а изменения схемы — проверенными миграциями.

Команды разработки из этого каталога: `npm ci`, `npm run db:migrate`, `npm test`, `npm run dev`, `npm run build`. Нужны Node.js 20.11+ и отдельная тестовая PostgreSQL. Настройки production и реальные секреты не входят в открытый репозиторий; в закрытом архиве `GSPro-live-*.tar.gz` исходники находятся в `live-site/`, база и ключи — в `transfer/`. Не подменять ключи шифрования при переносе существующей базы.

Приём новых платежей переключается в админке над каталогом и проверяется сервером по `TechnicalSettings.checkoutEnabled`. Уже начатые платежи продолжают сверяться. Условия подключения провайдера и проверки нового сервера описаны в инструкции развёртывания. Сайт включает независимые SMTP-профили, настраиваемые права ролей, уведомления и отключение 2FA через пароль и код из письма.
